# h2py

PyO3-style CPython extension modules in Haskell, on [pure-borrow](https://github.com/SoftwareFoundationGroupAtKyotoU/pure-borrow).

A module is a Haskell module with a few splices and a two-line C file.
A Python object reference is a borrow of an arena-owned slot (`Bound π t = Mut π (PyRef t)`, `Borrowed π t = Share π (PyRef t)`), a class is a Haskell payload type behind `pyclass`, and everything that may touch the interpreter runs in `Py π γ`, a `BIO` with one more index for the attachment scope.
Python errors are values (`PyResult a = Either PyErr a`); Haskell exceptions are the exceptional path and poison what the call holds mutably.

## Modules

| Module | What it holds |
|---|---|
| `H2Py` | The prelude: re-exports the modules below, and the tutorial in its Haddock. |
| `H2Py.Py` | The world `Py π γ` and the delimiters `attach`, `attach'`, `detach`, `parPy`. |
| `H2Py.Object` | `Bound`, `Borrowed`, `PyHandle`, the built-in tags, protocol operations, constructors, `copyOut`. |
| `H2Py.Class` | `PyClass`, `newObject`, `derefMut`, `derefShare`, `copyPayload`, and the `Slot` GADT of `H2Py.Class.Slot`. |
| `H2Py.Convert` | `FromPy`, `ToPy`, `PyTypeHint` and the `TypeHint` a stub renders. |
| `H2Py.Exception` | `PyErr`, `PyResult`, `orFail`, `orThrow`, the built-in exception tags, `ToPyErr`. |
| `H2Py.Module` | `ModuleDesc`, `renderStubs`, `checkStubs`, the `FromArg`/`ToResult`/`PyCallable` classes of the call boundary. |
| `H2Py.TH` | The splices `pyclass`, `pymethods`, `pymodule`, `newException` and their option combinators. |
| `H2Py.Runtime` | The attachment check and the opaque foreign types. |
| `H2Py.Buffer` | Reserved for Phase 4 (NumPy buffers). |

Each has `.Internal` (the definitions) and, where needed, `.Unsafe` siblings, on pure-borrow's suffix convention.

The C side: `cbits/h2py.c` is the shim (attachment, arenas, the lend state, the release pool), `cbits/api.c` wraps every CPython function the Haskell side calls, `cbits/rts_init.c` starts the GHC runtime, and `include/h2py/init.h` expands `#define H2PY_MODULE name` into the module's `PyInit_`.
`include/h2py/weakapi.h` is generated by `scripts/gen-weakapi.sh` and marks every CPython symbol weak on macOS, so that GHC can load the library to run Template Haskell without an interpreter.

## Building

The library includes `<Python.h>`, whose directory `scripts/configure-python.sh` takes from the target interpreter's `sysconfig` and writes into `cabal.project.local`; see the repository README for the full toolchain and `docs/tutorial.md` for how to write a module.
The `abi3t` flag targets the free-threaded stable ABI of CPython 3.15 and later and is off by default.
